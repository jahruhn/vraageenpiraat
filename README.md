# Vraag een Piraat! / Ask a Pirate

A simple, SEO-optimized search page for the Piratenpartij, allowing users to ask questions and search trusted sources using DuckDuckGo.

## Features

- **Search Bar:** Quickly search in Piratenpartij sources:  
  - [wiki.piratenpartij.nl](https://wiki.piratenpartij.nl)  
  - [piratenpartij.nl](https://piratenpartij.nl)  
  - [pp-international.net](https://pp-international.net)
- **SEO Optimized:** Includes meta description, keywords, and semantic HTML.
- **Accessible:** Uses proper labels and semantic tags.
- **Design:** Purple-themed search bar and highlights, using the open source [Ubuntu font](https://fonts.cdnfonts.com/css/ubuntu).

## Usage

1. Clone this repository.
2. Open `index.html` in your browser.
3. Enter your question in the search bar and click "Search" to query DuckDuckGo with Piratenpartij sources.

## Customization

- To change the font, update the stylesheet link in the `<head>`.
- To adjust colors, modify the CSS in the `<style>` block of `index.html`.
